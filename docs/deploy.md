# Запуск на сервере — пошагово

Инструкция для человека без опыта. После неё у вас будет адрес вида `https://…`,
по которому команда откроет приложение на телефоне и установит его на экран «Домой».

Займёт около 30–40 минут. Команды ниже нужно **копировать целиком** и вставлять в окно терминала.

## Словарик

* **VPS (виртуальный сервер)** — компьютер в интернете, который вы арендуете помесячно.
* **IP-адрес** — номер сервера в интернете, например `203.0.113.5`.
* **SSH** — способ подключиться к серверу и давать ему команды текстом.
* **Docker** — программа, которая запускает приложение «в коробке» со всем нужным внутри.
* **HTTPS** — защищённое соединение (замочек в адресной строке). Без него уведомления на телефонах не работают.

## Шаг 1. Арендовать сервер (~300–600 ₽ в месяц)

Подойдёт любой провайдер VPS (например, Timeweb Cloud, Selectel, REG.RU). При заказе выберите:

* операционная система: **Ubuntu 24.04**;
* память: **2 ГБ** (с 1 ГБ сборка может не поместиться — см. шаг 4);
* обязательно **публичный IPv4-адрес**.

После оплаты в личном кабинете провайдера будут **IP-адрес** и **пароль root**. Запишите их.

## Шаг 2. Подключиться к серверу

* **Windows 10/11:** нажмите «Пуск», напишите `PowerShell` и откройте его.
* **Mac:** откройте программу «Терминал».

Введите (вместо `203.0.113.5` — ваш IP-адрес):

```bash
ssh root@203.0.113.5
```

На вопрос `Are you sure you want to continue connecting` напишите `yes` и нажмите Enter.
Затем вставьте пароль root. **Пароль при вводе не отображается** — это нормально, просто нажмите Enter.

Теперь все команды выполняются уже на сервере.

## Шаг 3. Установить Docker и Git

```bash
curl -fsSL https://get.docker.com | sh
apt-get install -y git
```

Это займёт 1–3 минуты.

## Шаг 4. Только для сервера с 1 ГБ памяти — добавить «запасную память»

Пропустите этот шаг, если у сервера 2 ГБ и больше.

```bash
fallocate -l 2G /swapfile && chmod 600 /swapfile && mkswap /swapfile && swapon /swapfile
echo '/swapfile none swap sw 0 0' >> /etc/fstab
```

## Шаг 5. Скачать проект

```bash
git clone -b claude/team-alert-app-060nh3 https://github.com/katapodnarkata/Medicine-.git /opt/team-alert
cd /opt/team-alert/deploy
cp .env.example .env
```

## Шаг 6. Указать адрес сайта

Откройте файл настроек:

```bash
nano .env
```

Измените две строки:

* `DOMAIN=` — адрес сайта. Если своего домена нет, напишите IP-адрес **через дефисы** и добавьте
  `.sslip.io`. Например, для IP `203.0.113.5`: `DOMAIN=203-0-113-5.sslip.io`
* `VAPID_SUBJECT=` — ваша почта после `mailto:`, например `VAPID_SUBJECT=mailto:ivan@mail.ru`

Сохранить и выйти: **Ctrl+O**, Enter, затем **Ctrl+X**.

## Шаг 7. Запустить

```bash
docker compose up -d --build
```

Первый запуск собирает приложение: **5–10 минут**. Когда команда закончится, проверьте:

```bash
docker compose ps
```

Оба сервиса (`app` и `caddy`) должны быть в состоянии `running`.

## Шаг 8. Открыть на телефоне

Откройте в браузере телефона `https://<ваш DOMAIN>` — например `https://203-0-113-5.sslip.io`.

* **iPhone (iOS 16.4 и новее):** откройте адрес в **Safari** → кнопка «Поделиться» → **«На экран „Домой“»**.
  Затем откройте приложение **со значка** на экране, зарегистрируйтесь и нажмите «Включить уведомления».
* **Android:** откройте адрес в **Chrome** → меню ⋮ → **«Установить приложение»** (или «Добавить на гл. экран»).
  Откройте со значка, зарегистрируйтесь и разрешите уведомления.

Проверка: один человек регистрируется диспетчером, другой — участником; диспетчер выбирает команду,
добавляет участника и нажимает «ОТПРАВИТЬ ВЫЗОВ». У участника должно прийти уведомление.

## Обновление приложения

Когда в проекте появятся изменения:

```bash
cd /opt/team-alert && git pull && cd deploy && docker compose up -d --build
```

Данные (пользователи, команды, история) при обновлении сохраняются.

## Если что-то не работает

* Посмотреть журнал сервера: `docker compose logs app --tail 50`
* Журнал HTTPS: `docker compose logs caddy --tail 50` — если сертификат не выдан, проверьте, что
  в `DOMAIN` правильный IP через дефисы и что у провайдера открыты порты 80 и 443.
* Скопируйте текст ошибки и пришлите его в чат — разберёмся.
