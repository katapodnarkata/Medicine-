# Выпуск приложения для iPhone — пошагово

> **Не обязательно.** Основной вариант — веб-приложение ([deploy.md](deploy.md)), оно работает на iPhone
> без App Store и подписки Apple. Эта инструкция нужна, только если решите выпускать нативное приложение.

Инструкция для человека без опыта программирования. Каждый шаг: **что делать** и **зачем**.

## Что уже сделано в коде

| Требование Apple | Где в проекте |
|---|---|
| Уникальный идентификатор приложения `com.medicine.teamalert` | `mobile/app.json` → `ios.bundleIdentifier` |
| Push-уведомления в «боевом» режиме (production) | `mobile/app.json` → плагин `expo-notifications`, `mode: "production"` |
| Приём уведомлений в фоне | `mobile/app.json` → `UIBackgroundModes: remote-notification` |
| Ответ на вопрос о шифровании (не используется) | `mobile/app.json` → `ios.config.usesNonExemptEncryption: false` |
| Кнопка «Удалить аккаунт» (обязательна, если есть регистрация) | экран «Профиль» |
| Настройки сборки | `mobile/eas.json` |

## Словарик

* **Apple Developer Program** — платная подписка разработчика (99 $ в год). Без неё нельзя поставить своё приложение на чужие iPhone.
* **App Store Connect** — личный кабинет на сайте Apple, где создают карточку приложения и раздают его.
* **TestFlight** — официальное приложение Apple для раздачи «тестовых» версий. Участник ставит TestFlight из App Store, а через него — наше приложение.
* **APNs** — служба Apple, которая доставляет push-уведомления на iPhone.
* **EAS** — облачный сервис Expo, который собирает приложение для iPhone. Свой Mac не нужен.

## Шаг 1. Apple ID (бесплатно, можно с телефона)

Нужен Apple ID с включённой двухфакторной защитой (подтверждение входа кодом).
Создать: <https://account.apple.com>.

## Шаг 2. Подписка Apple Developer Program (99 $ в год)

Сайт: <https://developer.apple.com/programs/enroll/>. Есть два варианта:

* **Как частное лицо (Individual)** — быстрее, в магазине разработчиком будет указано ваше имя.
* **Как организация (Organization)** — например, от имени больницы. Нужен бесплатный номер **D-U-N-S**
  (международный номер организации), его оформление занимает до 2 недель. Нужны права подписи от организации.

⚠️ Оплата: Apple может не принять карту российского банка. Заранее уточните способ оплаты.

## Шаг 3. Сервер в интернете с HTTPS

Приложение для iPhone подключается **только** к серверам с защищённым адресом `https://...`.
Перед сборкой сервер (папка `server/`) должен работать в интернете. Его адрес нужно указать в
`mobile/app.json` → `extra.apiUrl`, например `https://alert.example.ru`.

## Шаг 4. Политика конфиденциальности

Apple требует ссылку на страницу с политикой конфиденциальности. Шаблон лежит в
[privacy-policy.md](privacy-policy.md): заполните поля в квадратных скобках и опубликуйте страницу
(на сайте организации или на любом бесплатном хостинге страниц).

## Шаг 5. Сборка (нужен компьютер, около 30 минут)

На компьютере должен быть установлен [Node.js](https://nodejs.org) (версия LTS). Команды вводятся в «Терминале».
Их нужно вводить в папке `mobile` проекта:

```bash
npm install                                         # скачать дополнения проекта
npx eas-cli@latest login                            # войти в аккаунт Expo
npx eas-cli@latest init                             # связать проект с Expo
npx eas-cli@latest build --platform ios --profile production
```

Во время сборки программа спросит логин и пароль Apple ID. Отвечайте **Yes (да)** на предложения
создать сертификаты и **ключ для push-уведомлений (APNs)**: EAS сделает их сам.

## Шаг 6. Отправка в App Store Connect

```bash
npx eas-cli@latest submit --platform ios --latest
```

Команда сама создаст карточку приложения в App Store Connect (если её ещё нет) и загрузит туда сборку.

## Шаг 7. Раздача команде через TestFlight

1. В App Store Connect откройте приложение → вкладка **TestFlight**.
2. **Внутренние тестировщики** (до 100 человек, которые добавлены в ваш аккаунт App Store Connect) получают
   сборку сразу, без проверки Apple.
3. **Внешние тестировщики** (до 10 000 человек, по e-mail или по общей ссылке) получат сборку после
   короткой проверки Apple, обычно за 1–2 дня.
4. Каждая сборка в TestFlight работает **90 дней**, потом нужно загрузить новую (повторить шаги 5–6).

## Шаг 8 (по желанию). Постоянная раздача без TestFlight

Приложение только для своей команды Apple может не пропустить в общий App Store. Подходящие варианты:

* **Unlisted App** — приложение есть в App Store, но найти его можно только по прямой ссылке.
  Запрос: <https://developer.apple.com/contact/request/unlisted-app/>.
* **Custom App** через Apple Business Manager — для организаций.

## Что указать в App Store Connect при проверке

* **App Privacy (конфиденциальность):** приложение собирает *имя* и *номер телефона*
  (Contact Info). Данные связаны с пользователем и нужны для работы приложения (App Functionality),
  для отслеживания (Tracking) **не** используются.
* **App Review Information:** напишите проверяющему, что регистрация открытая. Можно выбрать роль
  «Диспетчер» и отправить вызов себе, если в команде есть второй зарегистрированный пользователь-участник.
  **Сервер должен работать во время проверки.**
* **Категория:** Medical или Productivity.
